# Dry deposition of coarse and larger dust

This repository contains the MATLAB analysis, input measurements, and submitted figure images for *Common Parameterizations Tend to Overestimate the Dry Deposition of Coarse and Larger Dust* by Amato T. Evan, Marcelo Chamecki, Jasper Kok, and Tong Ying, submitted to *Atmospheric Chemistry and Physics* (ACP). A DOI is pending.

The study derives a mass-conserving dry-deposition formulation, calibrates it with the Zhang et al. (2014) wind-tunnel measurements, and compares deposition estimates across settling and deposition schemes. The submitted paper contains nine figures. See [figures/README.md](figures/README.md) for the source of each image and its generator.

## Contents

- `src/`: physical functions, Zhang 2014 ingest and fits, and all computational figure scripts.
- `data/zhang2014/raw/Zhang14.csv`: the digitized laboratory measurements used for calibration. See [data/README.md](data/README.md) for provenance, units, and generated outputs.
- `figures/paper/`: the nine image files supplied with the submitted manuscript.
- `figures/generated/`: outputs from a local reproduction run. Git ignores this directory.

## Run the analysis

Use MATLAB R2023b or newer with the Statistics and Machine Learning Toolbox (`prctile`). From the repository root:

```matlab
addpath(fullfile(pwd,'src'))
run_paper_figures
```

The entry point ingests `Zhang14.csv`, fits the mass-conserving and electric-analogue formulations with 2,000 accepted Monte Carlo realizations each, and writes plots to `figures/generated/`. The fit is the slow step. With the two generated result `.mat` files already present in `data/zhang2014/results/`, run `run_paper_figures(false)` to redraw figures without refitting. Outputs in `data/zhang2014/derived/` and `data/zhang2014/results/` are generated locally and ignored by Git.

Figure 1 is an author-created schematic. The remaining figures are generated by `src/plot_rebound_probability.m`, the Zhang fitting and plotting steps in `src/zhang2014/`, `src/plot_physics_comparisons.m`, and `src/plot_parameter_uncertainty.m`.

## Reproduction note

The committed `figures/paper/` images are the files accompanying the ACP submission. The scripts preserve the analysis code used to make them; rerunning can produce slightly different image rendering across MATLAB versions.

The manuscript's code availability statement points to this repository. Cite the paper when its DOI is available; the software citation metadata is in [CITATION.cff](CITATION.cff).
